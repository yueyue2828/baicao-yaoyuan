# 百草药园

一款以中药文化为主题的可爱 2D 放置刷宝 RPG。玩家经营药田、收集带有随机品质与词条的永久母株、配置弟子与方剂 BD，并通过全自动战斗攻略不同任务和副本。

首个目标是制作可独立安装、完全离线运行的 Windows 纵向切片 Demo。

## 当前状态

- 完整游戏设计文档已经建立；
- Windows Demo 纵向切片设计已经确认；
- 主美术方向锁定为“百草绘卷”；
- 计划技术栈为 Vue 3、TypeScript、PixiJS 与 Tauri 2。

设计资料位于 [`docs/superpowers/specs`](docs/superpowers/specs)。
