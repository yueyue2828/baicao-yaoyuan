# 《百草药园》Windows Demo 实施路线

本路线把纵向切片拆为四个可独立审查、可独立运行的实施计划。每个阶段都必须在前一阶段通过测试并推送到 `main` 后开始。

| 阶段 | 交付结果 | 主要范围 |
|---|---|---|
| 1. 工程基础与应用空壳 | 可安装、可缩放、可测试的 Windows 空壳 | Vue、Pinia、PixiJS、Tauri、配置校验、路由、CI |
| 2. 药田与母株闭环 | 可以种植、离线结算、收获、鉴定和保存母株 | 种植领域、随机词条、收藏、原子存档、备份恢复 |
| 3. BD 与战斗闭环 | 可以配置三套 BD、挑战关卡并阅读战斗报告 | 弟子、方剂、自动规则、确定性战斗、奖励与 Boss |
| 4. 内容与发布验收 | 达到 30～45 分钟纵向切片并生成公开安装包 | 坐诊、图鉴、文化安全、美术替换、平衡模拟、安装测试 |

阶段 2～4 在各自开始前，根据已完成代码的真实接口分别编写详细实施计划，避免预先假设尚未建立的文件和类型。
